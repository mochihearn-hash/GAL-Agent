# 0.2.0 LangChain Agent

关闭旧版本后，运行 `release/GAL-Agent-0.2.0/GAL Agent.exe`。应用名称与数据目录保持一致，原会话、模型配置和 Windows 凭据继续使用；旧版本发布目录保留。

## 运行流程

游戏流程使用 LangChain `create_agent` 与自定义中间件：观察节点截图并装配记忆；模型节点同时判断画面、上一动作结果和当前动作；校验与执行节点负责输入、等待或请求人工引导。

普通一轮仍只有一次视觉模型调用，没有新增规划、反思或独立反馈请求。触发长剧情摘要或遇到可重试网络错误时仍可能产生额外请求。动作 JSON 不符合约定时保存原回复与字段错误并暂停，不让框架自动请求修复。

文字逐字显示、转场或加载时等待两秒后重新截图，最多额外两次。原剧情动作重试最多额外两次，两类计数独立。模型选择等待时不会自动点击；未确认选择的重试保持原分支，并使用当前选项坐标。

运行提示改为“模型正在判断画面、上一操作和下一动作”，不再显示括号内的第几轮。轮数仍记录在本地历史中，便于排查重复请求。

## 模型与恢复

通过 LangChain 标准聊天模型接口对接原有 Chat Completions、Anthropic Messages 与 Gemini GenerateContent 协议。自定义 URL、API Key 保存与默认配置复用保持可用；没有要求用户模型支持额外的 tool calling 协议。

每次只发送当前截图。已读剧情仍通过近期记录、累积摘要、事实、推测和引导提供；不会把所有历史截图堆入模型上下文。摘要也使用 LangChain 模型接口。

会话、动作日志与检查点继续存入本地 SQLite。关闭重开后重新选窗口并确认对齐；没有把框架恢复变成自动重放鼠标点击。真实输入仍检查窗口身份、前台焦点、几何、遮挡与按键白名单。

## 源码环境

LangChain 已安装到项目 `.venv`，实际版本固定在 `backend/requirements.lock.txt`。首次搭建可运行 `scripts/Setup.ps1`；独立打包版内置框架依赖，无需额外安装 Python 或 LangChain。

新增和重构代码保留中文注释。验证记录见 `docs/VALIDATION.md`；真实模型与商业游戏测试由用户完成。
