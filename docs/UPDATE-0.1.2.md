# 0.1.2 悬浮窗与自动恢复

先关闭旧版，再运行 `release/GAL-Agent-0.1.2/GAL Agent.exe`。新版继续使用原来的用户数据目录，会话无需迁移。旧版目录不会被覆盖，请避免同时运行两个版本。

主窗口完成会话、模型与游戏窗口配置后，点击“悬浮窗”。它包含剧情理解、下一步动作、简短理由、人的引导，以及固定的运行状态和开始/继续、暂停/接管按钮。

观看模式不会获得键盘焦点，按钮可以直接点击。拖动顶部移动窗口；收起后保留控制栏。打开时会尝试放到游戏旁边的空白区域；游戏占满屏幕时，请自行移动悬浮窗避开对白和选项。遮住执行目标仍会拒绝输入。

点击“编辑引导”先暂停，再获得输入焦点。“返回观看”恢复不抢焦点的状态。发送引导不会自行开始操作，需要点击继续，并让游戏获得前台焦点。

重启或动作结果未确认时，先核对游戏画面与 Agent 记忆，再点击悬浮窗中的“进度已对齐”，即可解锁继续按钮。这个确认入口在收起状态下也可使用。

游戏失焦期间只停止输入，保留当前运行任务。回到前台后核对文字/选项区域和窗口映射：仍是原剧情时可复用保留的决策；剧情已经变化时重新观察，不补点旧动作。用户主动暂停、接管、引导、切换会话或修改配置都会使待执行动作失效，不因重新获得焦点而自行继续。

动作发送后，默认等待操作间隔 1 秒，再最多等待 5 秒剧情反馈。原对白或选项仍稳定且没有变化时，默认最多重试 2 次，总提交次数最多 3 次。每次重试都有独立动作记录、截图与原决策引用，不再为同一次重试请求模型。“操作设置”可调整反馈等待和重试上限，设为 0 可关闭自动重试。

部分系统输入提交失败、目标关闭、坐标变化、遮挡或修饰键按下不会自动重试。关闭或崩溃后仍默认暂停，未确认动作不自动重放，需重新绑定并核对游戏进度。

画面变化判断基于配置区域的像素特征，不能证明游戏内部状态一致；特殊动画、很小的文字差异和游戏不接受系统输入仍需实际适配。商业游戏测试由用户进行。
