# 0.1.5 模型驱动游戏 Agent

关闭旧版后，运行 `release/GAL-Agent-0.1.5/GAL Agent.exe`。继续使用原会话、模型配置和凭据，无需迁移；旧版本目录保留。

## 运行循环

截图 → 模型判断当前画面、上一操作结果和下一动作 → 校验格式及窗口权限 → 执行 → 下一轮截图。

一轮只发一次视觉决策请求。整个游戏客户区截图和记忆一同发送，模型自行识别转场、加载、逐字显示、完整对话、选项、菜单或无法辨认。下一轮在同一回答中判断上一操作是否推进，没有独立反馈请求。

移除运行中的像素稳定等待、台词字符串对比否决、模型响应后及发送前的像素变化作废。人物眨眼、背景动画、闪烁推进标记不再触发程序反复请求。界面移除了不再生效的稳定等待与对话区域参数，旧字段仅保留用于读取已保存配置。

## 动作与限制

- 转场、逐字显示和加载中自动等待2秒后重新截图读取，最多额外两次，仍未就绪则暂停。
- 完整对白或其他可等待状态下，尊重模型的 `wait`，不会因为反馈是 `same` 就自动补点；等待同样最多额外两次。
- 模型判断原剧情未推进且提出重复操作时，最多额外执行两次。读取与操作分别计数，首次不计入额外次数。点击重试可在设置中减少或关闭。
- `advance` 按用户配置点击对话区域或发送按键。选项由模型选择 `choose_option`，使用本次截图的按钮坐标；未确认成功的原选择不能改投其他分支。
- `request_help` 暂停并显示理由。普通动画不导致程序作废；窗口身份、位置、尺寸、焦点、坐标、遮挡、运行版本和控制心跳继续检查。
- 模型请求期间或发送前失焦后重新截图决策，避免恢复时点击已经由人改变的画面；已发送的输入仍保留待确认状态。

文字未完整、重复或等待中的观察不重复写入剧情记忆。关闭、暂停、引导、切换会话仍使旧任务失效；重启不自动补点，继续前需绑定并核对进度。

## 查看运行结果

状态提示包含第几轮，历史中保留每轮模型判断、实际操作及模型反馈。动作格式失败时保存原始回复、错误字段和当时截图，界面可展开查看；没有额外格式修复请求，校验失败不会执行输入。

剧情判断依赖模型的视觉能力。开发检查使用模拟模型和隔离测试窗口，真实游戏与实际接口速度由用户测试。长剧情摘要及网络重试仍可能产生额外模型请求。
