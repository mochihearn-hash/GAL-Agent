# 0.2.1 欢迎页看板娘背景

关闭旧版本后，运行 `release/GAL-Agent-0.2.1/GAL Agent.exe`。沿用原有会话、模型配置和 Windows 凭据，无需迁移数据。

## 界面变化

- 欢迎页中央移除装饰图标、中英文标题、说明文字和底部功能介绍，只保留创建会话按钮。
- 使用用户提供的 Claude 看板娘图片作为背景，以 CSS 轻微柔焦、降低饱和度和浅色渐变蒙层营造朦胧效果；按钮保持清晰并放在下方，避开人物脸部。
- 原始图片打包到本地资源中，离线可加载；装饰背景不参与游戏截图，也不会上传给模型。
- 会话侧栏、顶部操作栏、进入会话后的工作区及悬浮窗继续保留原有功能。
- 主窗口版本与后端版本更新为 0.2.1。README 提供 GitHub Releases 下载入口。

## 运行与验证

本次仅修改界面与版本资料。LangChain 决策、两秒等待、最多两次重试、权限检查、会话记忆及恢复规则保持原有行为。

源码同步到 GitHub；Windows 压缩包由用户手动发布到 Releases。验证结果见 `docs/VALIDATION.md`。
