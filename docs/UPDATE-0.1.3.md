# 0.1.3 使用说明

关闭旧版应用后，运行 `release/GAL-Agent-0.1.3/GAL Agent.exe`。旧版发布目录保留；新版继续读取同一用户数据目录中的会话、配置和凭据引用。

## 推进和反馈

- 普通对话只使用 `advance`。模型不能用空格或自选点击绕过会话配置。
- 选择“点击对话区域”后，在操作设置预览中标记实际能推进的位置。默认位置仍为窗口宽度50%、高度85%。
- 点击分为移动、等待、按下、保持和松开；默认移动后等待50毫秒、保持100毫秒。暂停、失焦和窗口改变会停止后续输入并释放程序按下的键或按钮。
- 局部像素变化仅触发核对。模型重新读取当前台词和选项，确认剧情变化后才认为推进成功；确认仍为原剧情后才允许有限重试。
- 反馈核对是额外的图片模型请求，会增加请求次数和等待时间。它不选择动作，也不会执行返回文本中的动作。
- 画面无法稳定、模型无法读清、核对期间画面变化或选项位置改变时，暂停或重新观察，保留未确认状态，不盲目重复输入。
- 悬浮窗及历史记录区分“模型建议”“实际操作”“系统接受输入”和“确认剧情变化”。

## 悬浮窗和配置

固定控制栏从左到右为“暂停 / 接管”“确认进度对齐”“开始 / 继续”；收起后也能使用。先暂停才能确认，且必须绑定当前会话的游戏窗口。确认只更新进度状态，不自动托管；点击继续后重新观察当前画面。

模型配置和 API Key 保存一次后持续复用。切换会话不会要求再次填写或测试；新会话默认复用最近保存或选择的模型配置。编辑配置时密钥留空仍表示保留已有密钥，只有明确选择移除才会删除。API Key 继续存放在 Windows 凭据管理器，数据库不存明文密钥。

## 摘要

摘要输入中的事实、推测和问题改为字符串数组，并提供明确输出结构。校验失败会保存原始响应和字段错误，最多修正两次。全部校验通过后才替换记忆；连续失败后暂停，保留原剧情和记忆，不无限重试或放大上下文。

## 验证边界

自动化测试使用独立会话数据、模拟模型及自建测试窗口。商业游戏与真实模型测试由用户进行；不能保证所有游戏都接受系统模拟输入，也不能保证模型准确识字。局部检测和模型内容核对减少已发现的漏判，不构成无误识别保证。
