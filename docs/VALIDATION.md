## 尚未验证与限制

- 没有真实模型 API Key，未验证实际供应商账号、模型图片识别效果、费用或真实剧情选择质量。
- 没有商业游戏运行环境，未验证《海猫鸣泣之时》《沙耶之歌》或其他特定游戏。
- 输入权限是前台检查与动作约束，不是系统级单窗口沙箱。
- 需要游戏自身的存档才能恢复游戏内部变量；Agent 检查点只恢复自身记忆。
- 摘要属于有损压缩，模型可能遗漏细节；原始记录和截图持续保留。
- 上下文预算采用保守估算，不是供应商精确 token 计算，图片用量由实际服务返回。
- 限时选项、实时战斗、复杂地图、连续文字动画和特殊字体需要进一步适配。
- 打包程序未配置代码签名；交付为包含资源的 Windows 应用目录和 ZIP，不是安装器。

## 重现方式

```powershell
npm run build
npm run test:backend -- -p no:cacheprovider --basetemp=F:\play_tool\test-results\backend-validation-new
npm test
```

`npm test` 串行执行实际桌面测试。打包测试在当前版本 `release/GAL-Agent-0.2.1/GAL Agent.exe` 不存在时会明确跳过；完整验收先执行 `npm run pack:dir`。

原生测试单独串行执行：

```powershell
.\.venv\Scripts\python.exe tests\native_smoke.py
```

截图位于 `test-results/main-window.png`、`test-results/overlay-window.png`、`test-results/packaged-window.png`；原生捕获报告位于 `test-results/native/report.json`。这些目录不进入版本库。

0.1.2 的失焦和动作重试测试使用模拟窗口、模拟帧和模型响应，验证任务与动作的行为；未通过商业游戏验收。悬浮窗测试核对实际 Electron 的 isFocusable 属性及按钮状态，观看模式不可获得键盘焦点，引导模式在后台暂停后才获得输入焦点。
