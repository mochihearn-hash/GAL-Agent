# 0.1.4 下一轮合并核对

关闭旧版后，运行 `release/GAL-Agent-0.1.4/GAL Agent.exe`。会话、模型配置和已保存的 API Key 继续使用原用户数据目录。旧版发布目录保留。

## 正常推进

模型读取当前剧情并给出动作，程序执行。下一轮的一次请求同时读取新截图、核对上一实际操作，并给出当前剧情的新决策。确认推进后立即采用该决策，不再独立发送反馈核对请求，也不再为了决策重复读取同一张画面。

稳定等待从操作后的截图开始，与操作间隔重叠。正常连续推进通常每张剧情画面一次决策请求；长剧情摘要、网络重试、加载重读及作废旧截图后的重新观察仍可能增加请求。

## 两类有限重试

| 状态 | 行为 | 上限 |
|---|---|---|
| 文字正在显示、加载中 | 等待2秒，重新截图并发起下一轮读取；不点击、不要求人立即回应 | 初次判断之外，最多额外读取2次；仍未就绪则暂停 |
| 明确仍是原对白或选项 | 下一轮核对完成后重试原决策，不接受同一句的新分支提议 | 默认最多额外执行2次；仍未推进则暂停 |
| 剧情已推进 | 清除原动作待确认状态，使用本次新决策 | 正常继续 |
| 无法确认或核对结果冲突 | 停止追加输入，提示接管或引导 | 暂停 |

等待重读与点击重试分别计数，首次不计入额外重试。未完整或重复的读取不重复写入剧情记忆。点击重试可以在操作设置中降至1次或关闭；旧配置中的3次在运行时按2次上限处理。

## 界面与恢复

主窗口和悬浮窗显示等待重读次数，历史中可查看核对结果与重读记录。原“反馈等待”改名为“画面稳定最长等待”，用于限制本地稳定检查，超过后交给模型读取，不代表每轮固定等待该时长。已保存配置字段保持兼容。

游戏失焦不发送输入；恢复后检查窗口与截图。暂停、引导、切换会话、重启使旧任务失效。已发送而未确认的动作仍保留进度对齐要求，不在重启后自动重放。

真实游戏和真实模型速度由用户测试。本版本开发检查使用隔离数据与模拟模型。
